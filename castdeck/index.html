Getting started

  1. Run CastDeck on macOS 13 or later. Connect the Mac and your receiver to the same local network.
  2. Allow Local Network access when macOS asks, then rescan the device list if necessary.
  3. Choose a video or audio file you own, or paste a direct media URL. A webpage URL is not a direct media URL.
  4. Select a Google Cast receiver and use Cast. For AirPlay, use the app's native AirPlay player and Apple's route picker.

CastDeck lists Google Cast, AirPlay and DLNA/UPnP receivers, CoreAudio outputs, and paired Bluetooth devices. Playback capabilities depend on the selected receiver. You can select compatible Google Cast devices for a synchronized session, or combine compatible system audio outputs.

Troubleshooting

No network devices appear

Check that both devices are on the same network. Guest networks and client isolation can prevent discovery. Check Local Network permission in macOS System Settings and use Rescan.

The receiver rejects a file

The receiver must support the file's codecs and container. MP4 with H.264 video and AAC audio is a useful starting point for Google Cast devices. CastDeck does not transcode unsupported files or bypass DRM.

AirPlay route selection

Apple's route picker controls AirPlay selection. CastDeck uses that supported system interface rather than forcing a route.

DLNA playback

DLNA devices must expose an AVTransport service. Compatibility varies, and playback has not yet been verified on the available test renderer.

App mirroring

App mirroring needs a compatible Google Cast receiver and macOS Screen Recording permission. Streaming has a delay, video is used by default, and protected content may appear black. Whole-screen AirPlay mirroring is provided by macOS Control Center.
