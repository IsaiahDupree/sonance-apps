# Driftlight support

Driftlight creates animated wallpapers from original scenes or media you select. Choose a scene, adjust its palette and movement, and save a Live Photo on iPhone. On Mac, open Driftlight Studio from the menu bar to manage your desktop scene.

## Save and test an iPhone wallpaper

1. In Driftlight, choose a wallpaper and tap **Save Live Photo to Photos**. Allow Photos add access when iOS asks.
2. In Settings, open **Wallpaper → Add New Wallpaper → Photos**, then choose the saved Live Photo.
3. Check whether the Live Photo motion control is available. If it is, turn it on, add the wallpaper, then lock and wake the phone to test motion.
4. If iOS disables motion, try turning off Low Power Mode and selecting the original Live Photo in Photos. Support varies by device, system version, and the individual photo. You can still use its still image.

## Restore a purchase

Open the Complete unlock screen on iPhone or the purchase screen in the Mac Studio and choose **Restore Purchases** with the Apple Account you used for the one-time purchase.
