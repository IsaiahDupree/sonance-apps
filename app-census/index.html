Know what’s installed.

Search your Applications folders and inspect app versions, signatures, App Store receipt status, size, and location on this Mac.

Using App Census

Choose Scan to inventory the system Applications folder. To include another Applications folder, open Folders and choose its location; macOS asks you to grant access. App Census remembers that permission on this Mac, and you can remove it from the same menu. Search or filter the list, select an app to inspect its local details, then choose Reveal in Finder to locate it.

An App Store receipt is evidence that macOS has an App Store receipt for the app. Its absence does not prove where the app came from. Signature status reports whether macOS validates the app’s code signature; it is one signal and not a complete security assessment.

The inventory stays on this Mac. Optional diagnostics export contains aggregate counts, selected filters, language/theme preferences, and local feature-use counts. It does not include app names or paths.
