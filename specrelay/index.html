SpecRelay · macOS

Support

Import OpenAPI specifications, compose and replay real API requests, and make selected operations available to local agent clients.

Getting started

Import an OpenAPI 3.0 or 3.1 JSON/YAML file, choose an operation, review the request fields, then send it to the base URL you configure. Save API credentials through the credential field; they are kept in macOS Keychain.

Agent gateway

The optional MCP server listens on loopback (127.0.0.1) and requires its bearer token. You choose which operations agents can access. Write operations remain disabled until you arm them in the app.

Troubleshooting

Check that the configured base URL is reachable, inspect the HTTP status and response body, and confirm that the selected credential matches the API. For unresolved references or unsupported OpenAPI content, contact support with a sanitized example.
