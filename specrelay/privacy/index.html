SpecRelay Support

Privacy Policy

Effective October 22, 2026

SpecRelay stores imported API specifications, workspace settings, request drafts, and response details in local app storage on your Mac. API credentials are stored in Keychain. A local MCP bearer token and small usage counters are stored in the app’s local preferences. If you export an agent configuration, it includes the local gateway token; save that file securely.

Network requests

When you press Send or an enabled local agent operation runs, SpecRelay sends the configured request, including the fields and credential you chose, directly to the API host in that workspace. That API host receives and processes the request and response. The optional MCP server binds to 127.0.0.1; it does not expose a public service. SpecRelay does not send workspace content, credentials, or usage counters to the developer.

Storage, analytics, and tracking

Workspace files, request drafts, responses, the local gateway token, and UI counters remain in the app’s local storage. The inspected release source has no analytics or advertising SDK and does not track users across apps or websites. The app’s privacy manifest declares no collected data and documents its local UserDefaults access; this policy does not replace the App Store privacy answers for a specific release binary.

Deletion

Delete a workspace in the app to remove its local workspace record and associated API credential from Keychain. Exported configuration files and copies of imported specifications are outside that deletion and must be removed separately.

Children

SpecRelay is a general-purpose productivity app and is not directed to children under 13. It does not knowingly collect personal information from children.

Changes and contact
