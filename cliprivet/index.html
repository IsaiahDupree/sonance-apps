ClipRivet

TikTok research workspace

Release status

ClipRivet is in development. Its App Store release is being prepared. A working research-service connection is required for online research; public service access has not yet been announced.

What ClipRivet does

ClipRivet's current development version lets you browse a loaded sample of observed TikTok posts, filter and order that sample, bookmark useful source evidence on your device, and open the original source.

Recorded counts and observation dates help you assess the evidence. The recent-only filter uses a 48-hour observation window. A loaded sample is not a complete TikTok ranking, and historical observations are not forecasts. Sound popularity does not give permission to reuse audio.

Connection help

  • Online research requires a compatible, reachable Market Tape service configured in Settings. A localhost address refers to the device running the app; it does not connect an iPhone to a Mac.
  • Draft generation additionally requires a compatible Script Hub service and device pairing. Do not enter provider API keys into the app.
  • Saved post evidence remains on each device. Previously saved metadata can be reopened without fetching it again; loading remote thumbnails can still require a network connection.
  • The Analyzer inspects only the image or video you select, using Apple's on-device frameworks. It does not upload that media.
